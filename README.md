# 📝 Hệ Thống Quản Lý Công Việc Cá Nhân (TaskFlow)

## 📌 Giới thiệu dự án
*TaskFlow* là ứng dụng web hỗ trợ người dùng tạo, theo dõi và phân loại tiến độ công việc hằng ngày. Dự án được xây dựng nhằm mục đích thực hành quy trình quản lý mã nguồn trên GitHub (Branch, Commit, Pull Request) và quản lý tiến độ bằng GitHub Projects.

## ✨ Các tính năng chính
- *Quản lý công việc (CRUD):* Thêm mới, chỉnh sửa, xóa và đánh dấu hoàn thành các đầu việc.
- *Phân loại trạng thái:* Chia công việc theo các nhóm trạng thái (Cần làm, Đang thực hiện, Hoàn thành).
- *Bộ lọc & Tìm kiếm:* Tìm nhanh công việc theo từ khóa hoặc mức độ ưu tiên.
- *Giao diện tương thích (Responsive):* Hiển thị tốt trên cả máy tính và điện thoại.

## 🛠️ Công nghệ sử dụng
- *Frontend:* HTML5, CSS3, Bootstrap 5, JavaScript
- *Backend:* PHP (PDO)
- *Cơ sở dữ liệu:* MySQL
- *Công cụ quản lý:* Git, GitHub, GitHub Projects
